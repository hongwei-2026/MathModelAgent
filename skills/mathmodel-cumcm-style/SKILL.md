# 数学建模论文格式 skill（自适应 + 三格式交付）

生成前**必须先询问使用者意图**（缺一不可），再选模板写稿。观感可参考 `论文参考/`，但不得把「国赛电子版禁忌」强加到明确要求目录/其他赛制的稿件上。

## 0. 生成前必问（意图卡片）

用简短选项确认：

1. **赛制/场景**
   - A. 国赛 CUMCM **电子版上传**（默认最严）
   - B. 国赛纸质正文对齐（仍无身份信息）
   - C. **其他建模竞赛 / 课程 / 专题论文**（亚太、长三角、校内等，按用户说明放宽）
2. **目录**
   - 无目录（CUMCM 电子版强制）
   - **有目录**（约 **2 页**，深度到二或三级；勿超过 2 页）
3. **摘要体例**
   - 赛题拆分体：仅当原文/用户确认存在「问题一/二/三」时，可用「针对问题…」
   - **主题叙述体**（默认用于科研专题、自拟题、无明确分问赛题）：背景→方法→结果数值→结论边界；**禁止虚构「针对问题一」**
4. **交付**
   - 默认同时：PDF + Word + LaTeX

未回答时：不要擅自用「针对问题一/二/三」；目录按用户上一次明确选择，否则先问再写。

## 1. 交付物（三版）

| 格式 | 用途 |
|------|------|
| PDF | 预览/上传 |
| Word (.docx) | 人工改字号与段落 |
| LaTeX (.tex) | 公式与终排 |

路径建议：`paper/CUMCM_*.pdf|.docx|.tex`（文件名可随题目调整）。

## 2. 场景规则矩阵

### A. CUMCM 2026 电子版

- 无承诺书、编号页、**无目录**、无页眉身份信息
- 第 1 页 = 题目 + 摘要 + 关键词；摘要**独占一页且尽量铺满**（不跨页）
- 页边距 ≥2.5cm；页脚居中阿拉伯数字，自摘要页=1
- 正文（不含附录）≤30 页；目标 20–28
- 字体：题三号黑居中；一级四号黑居中；二/三级小四黑左齐；正文小四宋；图题五号宋

### B/C. 其他赛制或「目录版」草稿

- 允许摘要后接 **约 2 页目录**，再进正文
- 摘要仍建议独占一页并**写满**；关键词 3–5 个
- 可保留国赛常用章节骨架，但标题与摘要**必须匹配真实任务结构**
- 若主办方另有模板（页边距/是否目录/是否英文摘要），以用户提供的模板为准，本 skill 作默认填充

## 3. 摘要（所有场景）

1. **铺满一页**：背景、数据与协议、方法链条、主要数值、局限与贡献；用足够正文+行距铺满，**禁止**用 `#v(1fr)` / 弹性空白把关键词顶到底部（会造成「上半有字、下半空白」）
2. **禁止**摘要内公式、图表、「见图」
3. **禁止**在无分问赛题时写「针对问题一/二/三」
4. 有分问时才用「针对问题…」，且每段含真实数值
5. 关键词 3–5，中文分号；紧接摘要末段，勿跨页
6. **专题/目录版**：摘要与目录页可不编阿拉伯页码；**从「一、…」正文起重新从 1 编号**

## 4. 版式细节（解决拥挤）

- 题目与「摘要」标题、摘要正文之间：**明确空行/竖向间距**（勿贴死）
- 一级/二级标题与随后正文之间：增加 `above/below` 间距，段意块之间可空行
- 连续排版，一级标题**不要**为灌页强制 `pagebreak`（摘要→目录或摘要→正文的换页除外）
- 主结果、对比、灵敏度：**三线表**；**表题在表上方**（`表N　标题`），图题在图下方（`图N　标题`）
- 关键模型名/指标**克制加粗**；图后必有解读段
- 正文（不含附录）**至少 20 页**；目录启用时目录约 2 页；页数必须主要靠**文字推导与分析**，禁止靠堆图凑页

## 4.1 插图硬约束（参考样图 ≠ 全部插入）

- 用户提供的截图/样图默认是**风格与结构参考**，**禁止**把多张参考流程图一次性塞进同一小节
- 同一小节（如「技术路线」）默认**最多 1 张**总览图；结构图、先验对比、决策流等放到**对应建模/检验小节**，图与图之间必须有正文隔开
- 流程图优先按正文内容**程序绘制**（清晰中文标注）；文生图仅作无关键文字的氛围插画，不得替代主证据图
- 禁止连续放置 3 张以上大型示意图而无解读文字

## 4.2 与科研绘图模板 skill 配合

结果类高质量统计图（SHAP、配对云雨、CV-ROC、泰勒图、相关矩阵组合、预测-真实边缘分布、环形热图、和弦图等）优先调用：

`../mathmodel-figure-templates/SKILL.md`

分工：

| 图类 | 用哪个 skill |
|------|----------------|
| 技术路线 / 架构 / 算法流程 | `4drawio` 或程序绘制示意图；遵守 §4.1 |
| 普通数据图（误差条、折线、三线表配图） | `3coding-visual` 用真实结果直接画 |
| 需要「期刊感」的复杂统计图 | `mathmodel-figure-templates` 选模板 → **换真实数据** → 导出 PDF 入 `figures/` |

写入正文时仍遵守本 skill：表题在上、图题在下、图后必有解读、禁止同节堆图；模板自带模拟数据**不得**当真实实验结果写进摘要/正文。

## 5. 推荐章节（可改名，勿生造分问）

通用骨架（无赛题分问时用「研究目标/实验模块」表述，不用「问题一」）：

1. 摘要、关键词  
2. （可选）目录  
3. 一、研究背景与问题重述  
4. 二、分析与技术路线  
5. 三、模型假设  
6. 四、符号说明  
7. 五、数据与模型建立（含 EDA；子节按真实模块）  
8. 六、结果与检验 / 敏感性分析  
9. 七、改进与推广  
10. 八、优缺点与结论  
11. 参考文献  
12. 附录（短：命令/超参/索引；正式参赛再补源码）

国赛分问赛题：可将第五章按问题一/二/三展开；摘要方可「针对问题」。

## 6. 附录与代码

- 学习获奖卷观感时：**不同步**其大段源码附录凑页
- 正式国赛终稿：附录按官方要求补可运行代码（控制体积）

## 7. 检查清单

- [ ] 已询问赛制、目录、摘要体例
- [ ] 摘要铺满一页且无大片底部空白；无 `#v(1fr)` 顶关键词；无虚构「针对问题」
- [ ] 表题在上、图题在下；示意图按章节分散，无连堆；复杂统计图经 figure-templates 且已换真实数据
- [ ] 标题与正文间距疏朗；有目录则约 2 页；正文页码从正文起编（若选用）
- [ ] 正文 ≥20 页且主要靠文字；国赛电子版 ≤30
- [ ] PDF + Word + LaTeX 齐全；三线表与真实数值可追溯
