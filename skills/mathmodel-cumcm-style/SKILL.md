# CUMCM 论文格式与观感规范（2026 官方 + 获奖正文）

生成国赛论文时**以本 skill 为准**。观感可参考 `论文参考/` 与获奖 zip，但**格式以官方电子版要求为准**。

## 0. 交付物（默认三版）

每次定稿默认同时产出，便于人工修改：

| 格式 | 用途 | 建议路径 |
|------|------|----------|
| **PDF** | 上传/预览 | `paper/CUMCM_*.pdf` |
| **Word (.docx)** | 人工改字号/微调 | `paper/CUMCM_*.docx` |
| **LaTeX (.tex)** | 公式/版式精修 | `paper/CUMCM_*.tex`（可附 `main.typ` 源） |

- 电子版文件 ≤20MB；禁止压缩包当作论文上传
- 三版**内容一致**（同一摘要页起编页码、同一章节与图表编号）
- Word：可用 Pandoc 从 LaTeX/Markdown 转换；转换后检查三线表与公式

## 1. 电子版 vs 纸质版（最高频踩坑）

### 电子版（系统上传 PDF/Word）— 本 skill 默认生成电子版

- **不要**承诺书、编号专用页
- **不要目录**
- **不要页眉**；严禁学校/姓名/队员/导师等身份信息
- 第 1 页 = **题目 + 摘要 + 关键词**（摘要独立成页，**禁止跨页**）
- 页脚居中阿拉伯数字，**从摘要页开始为 1**
- 第 2 页起正文；正文结束 → 参考文献 → 附录
- 正文（不含附录）**≤30 页**；目标观感约 **20–28 页**

### 纸质版（仅提醒，默认不生成）

第 1 页承诺书 → 第 2 页编号页 → 第 3 页摘要（页码从此为 1）→ 正文…  
电子版正文部分须与纸质正文完全一致。

## 2. 页面与字体（强制）

| 项 | 要求 |
|----|------|
| 纸张 | A4；页边距 **≥2.5cm**（四边） |
| 页眉 | **禁止** |
| 行距 | **单倍行距** |
| 段落 | 正文首行缩进 2 字符；两端对齐 |
| 西文/数字 | Times New Roman |
| 题目 | **三号黑体**，居中 |
| 一级标题 | **四号黑体**，居中（可用「一、二、…」或「1、2、…」，全文统一） |
| 二/三级标题 | **小四黑体**，**左对齐不居中** |
| 正文/摘要/关键词/参考文献/附录 | **小四宋体** |
| 图表标题 | **五号宋体**；图题在下、表题在上 |

Typst/LaTeX 近似字号：三号≈16pt，四号≈14pt，小四≈12pt，五号≈10.5pt。

## 3. 摘要硬性要求

1. 独立一页，不跨页；无需英文摘要
2. 结构：问题简述 → 模型与方法 → 求解结果 → 模型评价  
   推荐用 **「针对问题一/二/三…」** 分段，每段含**真实数值**（勿编造）
3. 关键词 **3～5 个**，中文分号分隔，紧跟摘要下方
4. **禁止**摘要内放公式、图表或“见图X”

## 4. 推荐正文结构（官方顺序）

1. 摘要、关键词（第 1 页）
2. 一、问题重述
3. 二、问题分析
4. 三、模型假设
5. 四、符号说明（**三线表**）
6. 五、模型建立与求解（可含数据处理/EDA 子节；按问题一/二/三深分层）
7. 六、模型检验 / 敏感性分析 / 误差分析
8. 七、模型改进与推广
9. 八、模型优缺点
10. 参考文献（GB/T 7714；正文引用用 [1][2]）
11. 附录

说明：数据处理/EDA 可作为「五、」下首节，不必单独成与官方冲突的大章名；灵敏度必须独立成章且有表有数。

## 5. 图表、公式与排版细节（用户强调）

1. 全文连续编号：图 1、图 2；表 1、表 2；公式 (1)、(2)
2. **主结果、对比、灵敏度、校准等数据优先用三线表**（顶线/栏目线/底线，**无竖线**）
3. 图后必须有解读段（「由图可见…」）；关键结论数字、模型名、指标名可**适当加粗**（勿整段加粗）
4. 段落：同节内逻辑块之间可**适当空行**分开（问题小结与下一问之间、图解读与下一小节之间）；避免“墙式一段到底”，也避免每章强制换页造成半页空白
5. 一级标题**禁止** `pagebreak` / 弱换页灌空白；摘要后换页进入正文是允许的唯一常规强制换页
6. 公式居中、编号靠右；变量斜体
7. Typst 中连续小数用 `\/`，避免 `$0.07/0.08$` 被排成叠分式

## 6. 附录与“代码不同步”的边界

- **官方要求**：正式参赛附录应含可运行源码与必要数据/推导
- **观感学习**：不要为对齐获奖卷总页数而粘贴其 MATLAB/Python 长清单
- **本项目默认草稿**：附录给复现命令、超参表、结果文件索引；若用户明确要求“参赛终稿”，再补注释完整的核心源码（控制体积，可与支撑材料压缩包一致）

## 7. 反例

- 电子版含承诺书/编号页/目录/页眉身份信息
- 摘要跨页或摘要含公式图表
- 正文＞30 页（不含附录）靠代码注水
- 每章强制换页大片留白；后半章空心
- 主结果只用散文罗列、从不用三线表
- 编造 CSV/报告中不存在的精度

## 8. 输出检查清单

- [ ] 电子版：无承诺书、无编号页、无目录、无页眉身份信息
- [ ] 第 1 页仅为题目+摘要+关键词；摘要不跨页；关键词 3–5 个
- [ ] 页边距≥2.5cm；页码自摘要页起为 1
- [ ] 字体层级符合三号/四号/小四/五号约定
- [ ] 主对比与灵敏度有三线表；图后有解读；关键处有克制加粗
- [ ] 结构含重述—分析—假设—符号—建模—检验灵敏度—改进—优缺点
- [ ] 正文≤30 页；同时交付 PDF + Word + LaTeX
- [ ] 数值可追溯；未为凑页粘贴参考卷大段代码
