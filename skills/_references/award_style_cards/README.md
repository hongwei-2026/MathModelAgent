# 获奖风格卡（蒸馏用）

往年完整 PDF **不要**整篇塞进模型上下文。写作前只 Read **一张**与本题型匹配的卡片。

## 如何新增一张卡

从 1–2 篇国一/美赛 O 奖卷抽取（每项 3–8 行即可）：

1. 一级/二级章节骨架（标题，不要正文）
2. 摘要节奏（背景→方法→带数结果→边界）
3. 表图密度（每节大约几张；表题上/图题下）
4. 灵敏度通常怎么写
5. **禁止学的**（代码附录灌页、连续堆 3 张大流程图等）

保存为 `award_style_cards/<name>.md`，并在 `PAPER_OUTLINE.md` 的 `style_card` 字段填写文件名（无后缀）。
