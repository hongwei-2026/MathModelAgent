# 风格卡：专题 / 科研叙述体（无问题一/二/三）

适用于自拟题、课程论文、量子/ML 专题等。**禁止虚构「针对问题一」**。

## 章节骨架

1. 摘要 + 关键词（主题叙述：背景→数据协议→方法链→**量化结果**→边界；铺满一页）
2. （可选）目录约 1–2 页
3. 一、研究背景与问题重述
4. 二、分析与技术路线
5. 三、模型假设
6. 四、符号说明
7. 五、数据与模型建立（EDA + 模块化方法；子节按真实模块，不按虚构题号）
8. 六、结果与检验 / 敏感性分析（主表 + 对照 + 诊断）
9. 七、改进与推广
10. 八、优缺点与结论
11. 参考文献 + 短附录（命令/超参，不大段源码）

## 摘要节奏

- 一段动机与任务定义（无公式、无「见图」）
- 一段数据与公平协议（N、划分、种子）
- 一段方法（编码器 / 先验 / 训练目标）
- 一段**带 ± 的主指标**与对照结论（只写 lock 允许的话）
- 一段局限（如校准差、OOD 负 R²）与贡献边界
- 关键词用主题词，不用「问题一」

## 表图密度

- 主结果一张总表胜过多张 parity 重复图
- 复杂统计图（Taylor / 雨云等）每类 1 张，放结果章
- 技术路线图最多 1 张放分析章

## 结果叙事（防夸大）

- 先报协议，再报表，再解释「谁赢在什么指标」
- 若某模型 MAE 更差，贡献应写协议公平性 / 采样 / 诊断，而非虚构最优

## 灵敏度

- 超参、种子、数据子集或先验温度等至少一类扰动
- 与 IID 主表分开写，避免混为一谈

## 禁止学的

- 「看板 / 以 CSV 为准 / 写作自检 / 答辩提示」等助手口吻
- 无分问时写「针对问题一/二/三」
- 堆叠多张近重复预测散点图
- 把内部路径 `reports/`、`checkpoints/` 写进正文
